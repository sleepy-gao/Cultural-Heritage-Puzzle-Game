# Cultural-Heritage-Puzzle-Game

传统文化主题的数字拼图游戏

一款基于 C++ 和 EasyX 图形库开发的 4×4 数字拼图游戏，融入 16 种中国传统文化元素，在游戏的同时感受中华文化的魅力。

## 功能特性

- 🎮 **4×4 滑块拼图**：经典的数字拼图玩法，将打乱的图片还原
- 🎨 **16 种传统文化主题**：每张拼图对应一种中国传统文化元素
- 🖱️ **鼠标 + 键盘双操作**：支持鼠标点击和 WASD/方向键移动
- ⏱️ **计时与步数统计**：实时显示游戏用时和移动次数
- ⏸️ **暂停功能**：按空格键暂停游戏
- 🎵 **背景音乐**：内置 China-Y 背景音乐
- 🎉 **胜利画面**：完成拼图后展示胜利界面

## 技术栈

- **语言**：C++
- **图形库**：[EasyX](https://easyx.cn/)（基于 Win32 GDI）
- **音频**：Windows MCI（mciSendString）
- **开发环境**：Visual Studio 2022（v143 工具集）

## 构建与运行

### 环境要求

- Windows 操作系统
- Visual Studio 2022（或更高版本）
- [EasyX 图形库](https://easyx.cn/)（需提前安装）

### 编译步骤

1. 使用 Visual Studio 打开 `程设综合项目.sln`
2. 选择配置（Debug / Release）和平台（Win32 / x64）
3. 点击「生成解决方案」进行编译
4. 运行生成的可执行文件

> **注意**：请确保 `images/` 文件夹、背景图片和音乐文件与可执行文件在同一目录下。

## 操作说明

### 主菜单

| 按键 | 功能 |
|------|------|
| ↑ / W | 上移选择 |
| ↓ / S | 下移选择 |
| Enter | 确认选择 |

### 游戏界面

| 按键 | 功能 |
|------|------|
| 鼠标点击 | 点击相邻方块移动 |
| ↑ / W | 空格向上移动 |
| ↓ / S | 空格向下移动 |
| ← / A | 空格向左移动 |
| → / D | 空格向右移动 |
| Space | 暂停游戏 |

### 图片选择

在 16 种传统文化主题中选择拼图图案，使用方向键或 WASD 选择，Enter 确认。
